🧮 Vector — собственная реализация динамического массива на C++
Учебный проект, в котором реализован аналог std::vector с полным контролем над управлением памятью, временем жизни объектов и обработкой исключений.

📋 Описание
Проект состоит из двух шаблонных классов:

RawMemory<T> — низкоуровневая обёртка над сырым буфером памяти. Отвечает за выделение, освобождение и перемещение блока памяти без создания объектов.

Vector<T> — динамический массив, построенный поверх RawMemory<T>. Управляет временем жизни элементов, поддерживает итераторы, копирование, перемещение и вставку в произвольную позицию.

Основная цель — показать, как std::vector устроен «под капотом»: как разделяются ответственности за память и за объекты, как обеспечивается строгая гарантия безопасности исключений и как выбирается между копированием и перемещением.

✨ Возможности
RawMemory<T>
Выделение и освобождение сырой памяти через operator new / operator delete

Конструктор перемещения и перемещающее присваивание

Операторы [] и + для доступа по индексу и смещению

Метод Swap для обмена буферами без копирования

Vector<T>
Конструкторы: по умолчанию, с размером, копирующий, перемещающий

Операторы присваивания: копирующий и перемещающий

Итераторы: begin, end, cbegin, cend

Resize, Reserve, PushBack, PopBack

Emplace, EmplaceBack — конструирование элемента на месте

Insert, Erase — вставка и удаление по итератору

Size, Capacity, operator[]
